# SmartOCR

SmartOCR is a professional desktop OCR and AI translation application.

Extract text from images and documents using advanced OCR technology,
then translate it using online or offline AI.

## ✨ Features

- Advanced OCR with PaddleOCR
- AI-powered translation
- Online translation with GapGPT
- Offline translation with Ollama
- Terminology management
- English, Chinese, Japanese, and Korean support
- Hardware-aware local AI model management
- Windows desktop application
- Fast and user-friendly PySide6 interface
